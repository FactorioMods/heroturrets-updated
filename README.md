# HeroTurrets: Updated

Turrets gain ranks through combat, letting established defenses grow stronger as they fight. Ranking and supported turret integrations remain configurable.

The Factorio 2.1 fork preserves turret quality, ammunition, fluids, health and circuit connections during promotions, and retains historical ranked Rampant turret items.

Requires Factorio 2.1.24 or later. Disable `heroturrets` before enabling this fork. Required content and optional integrations are listed in the mod dependencies.

## Technical validation

Headless Factorio 2.1.24 checks covered importing and reloading an existing game. A separate native fixture retained 48 historical ranked turret item names in held items and inserter/blueprint filters.
